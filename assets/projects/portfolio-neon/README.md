# rishabhsxngh.github.io — Neon template

Drop-in GitHub Pages site. To deploy:
1. Replace everything in your repo root with the contents of `template-c-neon/` (keep `.nojekyll`).
2. Search index.html for `TODO` — the ReStock Verify GitHub link needs the repo URL.
3. Push.

Everything is a single index.html (CSS inline). Experience and projects use native <details> dropdowns, no JS needed.
